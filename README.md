# 📝 Full-Stack Todo App (Django + React)

This repository contains the source code for a Full-Stack **Todo App** built using **Django** (backend) and **React** (frontend).  
The project is created as part of my article series: 

**📚 Django + React: From Scratch to App**  
A hands-on guide focused not only on *how* to write code, but also on *why* each step matters.
https://medium.com/@pataspatek 

---

## 🚀 Project Overview

The goal of this project is to build a simple, functional Todo application while understanding:

- How Django handles backend logic and APIs  
- How React manages UI and state  
- How these two technologies communicate  
- Why each part of the stack is necessary  
- How to structure and scale a full-stack project  

This repository will grow alongside the article series.
